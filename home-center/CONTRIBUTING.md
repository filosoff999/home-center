# Contribution Guide

1. Создайте короткоживущую ветку.
2. Свяжите изменение с issue и `HC-*` requirement.
3. Выполните `make ci`.
4. Откройте Pull Request.
5. Дождитесь GitHub-hosted CI.
6. Для production-impacting изменения приложите rollout, rollback и evidence plan.

Home Center не принимает cross-product dependencies или изменения за пределами этого репозитория.
