Как установить Home Center дома

Сейчас установка рассчитана на человека, который уже немного знаком с Linux. Ниже все шаги идут по порядку: скачать, проверить, подготовить настройки, установить и запустить.

Перед началом

Что понадобится

Для текущей публичной версии нужен Linux-сервер с Python 3.12+, OpenSSL, systemd, tar и sha256sum. Готовая сборка 0.14.0 предназначена для обычных 64-битных процессоров amd64.

Установка 0.14.0 не перенастраивает домашнюю сеть автоматически.

Сетевые функции Home Center — правила доступа, VPN, фильтрация и другие возможности — подключаются отдельными модулями и включаются владельцем явно. Сам установщик 0.14.0 не меняет роутер, DNS, DHCP, NAT или firewall.

Шаг 1

Скачайте два файла

На странице релиза нужны: архив Home Center и файл с контрольной суммой .sha256. Контрольная сумма нужна, чтобы убедиться, что архив скачался без повреждений.

Текущая версияhome-center-free-0.14.0-linux-amd64.tar.gz+ home-center-free-0.14.0-linux-amd64.tar.gz.sha256
Открыть 0.14.0

Удобнее также скачать или клонировать публичный репозиторий Home Center Free: в нём находятся скрипты установки и примеры настроек.

Шаг 2

Проверьте скачанный архив

Эта команда проверит контрольную сумму и содержимое архива. Если файл повреждён или не соответствует ожидаемой версии, установка не продолжится.

bash deploy/scripts/home-center-release.sh verify \
  --artifact home-center-free-0.14.0-linux-amd64.tar.gz \
  --checksum home-center-free-0.14.0-linux-amd64.tar.gz.sha256
Шаг 3

Подготовьте настройки и сертификаты

Скопируйте пример deploy/config/config.node-a.example.json в отдельный защищённый каталог и замените примерные значения своими. Для защищённого соединения Home Center также нужны сертификаты.

Почему это пока не делается одной кнопкой?

Версия 0.14.0 — техническая версия для самостоятельной установки. Упрощённая домашняя настройка готовится для следующих версий.

Шаг 4

Установите Home Center

В команде ниже замените пути /secure/path/... на реальные пути к вашим файлам. Команда установит Home Center, но пока не запустит его автоматически.

sudo bash deploy/scripts/home-center-release.sh install \
  --artifact home-center-free-0.14.0-linux-amd64.tar.gz \
  --checksum home-center-free-0.14.0-linux-amd64.tar.gz.sha256 \
  --config /secure/path/config.json \
  --peer-cert /secure/path/peer.crt \
  --peer-key /secure/path/peer.key \
  --cluster-ca /secure/path/cluster-ca.crt \
  --web-cert /secure/path/web.crt \
  --web-key /secure/path/web.key \
  --web-ca /secure/path/web-ca.crt
Шаг 5

Запустите Home Center

После установки включите сам Home Center и автоматический таймер резервного копирования.

sudo systemctl enable --now \
  home-center.service home-center-backup.timer

systemctl status home-center.service

Если хотите запустить сервис сразу во время установки, к команде установки можно добавить --start.

Обновление

Как установить новую версию

Скачайте архив новой версии и его файл .sha256, сначала проверьте их командой verify, а затем выполните update. В примере ниже указана 0.14.0; для будущей версии имя файла нужно заменить.

sudo bash deploy/scripts/home-center-release.sh update \
  --artifact home-center-free-0.14.0-linux-amd64.tar.gz \
  --checksum home-center-free-0.14.0-linux-amd64.tar.gz.sha256
Настройки сохраняются/etc/home-center
Данные сохраняются/var/lib/home-center
Резервные копии сохраняются/var/backups/home-center
Сертификаты сохраняютсяобновление не заменяет ваши ключи и сертификаты

Новая версия сначала распаковывается отдельно. Home Center проверяет её и только после этого переключается на неё. Если после переключения сервис не запускается, установщик пытается вернуть предыдущую рабочую версию.

--no-restart позволяет обновить файлы без немедленного перезапуска. --allow-downgrade разрешает вручную перейти на более старую версию.

Если что-то пошло не так

Как вернуть предыдущую версию

Старые проверенные версии хранятся в /opt/home-center/releases. При ручном откате нужно остановить Home Center, переключить /opt/home-center/current на нужную старую версию, выполнить systemctl daemon-reload и снова запустить сервис.

Не путайте откат программы и резервную копию данных.

Перед удалением старых версий и перед серьёзными изменениями лучше иметь отдельную резервную копию важных данных.
