Установка и обновление дома

Текущая установка рассчитана на пользователя, который умеет работать с Linux. Ниже — короткий путь от скачанного архива до запущенного Home Center, без скрытой настройки вашей сети.

Перед началом

Что понадобится

Поддерживаемая публичной инструкцией платформа — Linux с Python 3.12+, OpenSSL, systemd, tar и sha256sum. Текущий опубликованный бинарный архив — Linux amd64.

Home Center не перенастраивает сеть сам.

Команды установки не меняют маршрутизатор, NAT, DNS, DHCP или firewall. Это остаётся под контролем владельца дома.

Шаг 1

Скачайте релиз и checksum

На странице последнего релиза скачайте два файла: архив Home Center и соответствующий файл .sha256.

Текущий релизhome-center-free-0.14.0-linux-amd64.tar.gz+ home-center-free-0.14.0-linux-amd64.tar.gz.sha256
Открыть 0.14.0

Рекомендуется сначала распаковать или клонировать публичный репозиторий, чтобы рядом были скрипты deploy/scripts/ и примеры конфигурации.

Шаг 2

Проверьте артефакт

До установки скрипт проверяет внешнюю SHA-256 сумму, безопасные пути архива, версию, revision и внутренний manifest.

bash deploy/scripts/home-center-release.sh verify \
  --artifact home-center-free-0.14.0-linux-amd64.tar.gz \
  --checksum home-center-free-0.14.0-linux-amd64.tar.gz.sha256
Шаг 3

Подготовьте домашнюю конфигурацию и TLS

Скопируйте пример deploy/config/config.node-a.example.json в отдельный защищённый путь и замените все примерные значения своими. Для установки также нужны отдельные peer mTLS и Web TLS сертификаты.

Почему сертификаты нужны уже сейчас?

Текущая 0.14.0 — технический релиз для самостоятельного развёртывания. Упрощение первоначальной установки и домашние deployment profiles входят в последующие направления развития.

Открыть инструкцию по сертификатам →

Шаг 4

Установите Home Center

Укажите свои защищённые пути к конфигурации и сертификатам. Без параметра --start сервис после установки не запускается автоматически.

sudo bash deploy/scripts/home-center-release.sh install \
  --artifact home-center-free-0.14.0-linux-amd64.tar.gz \
  --checksum home-center-free-0.14.0-linux-amd64.tar.gz.sha256 \
  --config /secure/path/config.json \
  --peer-cert /secure/path/peer.crt \
  --peer-key /secure/path/peer.key \
  --cluster-ca /secure/path/cluster-ca.crt \
  --web-cert /secure/path/web.crt \
  --web-key /secure/path/web.key \
  --web-ca /secure/path/web-ca.crt
Шаг 5

Запустите сервис

После проверки конфигурации включите основной сервис и таймер резервного копирования.

sudo systemctl enable --now \
  home-center.service home-center-backup.timer

systemctl status home-center.service

Альтернатива: добавить --start к команде установки.

Обновление

Как перейти на новый релиз

Скачайте архив новой версии и его checksum, проверьте их тем же verify, затем выполните update. Ниже имя 0.14.0 показано только как формат команды — при следующем релизе замените его на новое.

sudo bash deploy/scripts/home-center-release.sh update \
  --artifact home-center-free-0.14.0-linux-amd64.tar.gz \
  --checksum home-center-free-0.14.0-linux-amd64.tar.gz.sha256
Конфигурация сохраняется/etc/home-center
Данные сохраняются/var/lib/home-center
Резервные копии сохраняются/var/backups/home-center
Сертификаты сохраняютсяключи и TLS identity не заменяются обновлением

Новый релиз разворачивается в отдельный каталог, после проверки manifest ссылка /opt/home-center/current переключается атомарно. Если ранее работающий сервис не смог перезапуститься, установщик возвращает ссылку на предыдущий релиз и пытается запустить его.

--no-restart переключает релиз без перезапуска, а --allow-downgrade явно разрешает переход на более старую версию.

Восстановление

Ручной rollback

Проверенные старые версии остаются в /opt/home-center/releases. Для ручного отката остановите сервис, атомарно переключите /opt/home-center/current на выбранный предыдущий каталог, выполните systemctl daemon-reload и снова запустите сервис.

Перед удалением старых релизов

Сохраните независимую резервную копию данных. Rollback приложения не заменяет backup пользовательских данных.
