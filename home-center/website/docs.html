Установка

Установите Home Center и начните с простого интерфейса.

Пользовательская установка выполняется из официального stable-канала. Текущий stable-релиз — Home Center 0.61.0.

Перед началом

Что понадобится

64-битный Linux-сервер с systemd, Python 3.12 или новее, SQLite, административный доступ и стандартные утилиты tar и sha256sum. TLS-идентичности для Web и межузлового взаимодействия предоставляет администратор. Для важных данных заранее подготовьте резервную копию.

Home Center не должен самовольно перестраивать домашнюю сеть.

Routing, NAT, port-forwarding, firewall и внешний доступ включаются только отдельными управляемыми действиями и только там, где соответствующая capability квалифицирована.

Шаг 1

Скачайте официальный source-архив и SHA256SUMS

Для чистой установки 0.61.0 используйте официальный source-архив Stable-релиза. Скачайте его вместе с SHA256SUMS из того же релиза.

Скачать
Шаг 2

Проверьте релиз и контрольные суммы

Перед установкой проверьте, что вы используете tag v0.61.0, а в релизе присутствуют SHA256SUMS, release manifest, acceptance evidence и SPDX SBOM. Затем в каталоге со скачанными файлами выполните:

sha256sum -c SHA256SUMS --ignore-missing
Продолжайте только после результата OK.

Контрольная сумма подтверждает целостность файла, но не заменяет проверку поддерживаемого install/upgrade path для вашей исходной версии.

Шаг 3

Распакуйте source-архив

mkdir -p home-center-0.61.0
tar -xzf home-center-0.61.0-source.tar.gz -C home-center-0.61.0
cd home-center-0.61.0
Шаг 4

Сначала подготовьте установку, затем активируйте

Authoritative инструкция конкретного релиза находится в INSTALL.md. Штатный установщик запускается с вашей конфигурацией:

sudo bash deploy/scripts/install.sh --config /path/to/config.json

Сначала выполняйте staging без активации. --activate добавляйте только после проверки конфигурации, systemd units, путей сертификатов, состояния backup и готовности rollback. Не переносите примерные значения конфигурации в рабочую среду без проверки.

Первый запуск

Сразу смените первоначальный пароль

После чистой установки создаётся локальная учётная запись admin с первоначальным паролем admin. При первом входе пароль обязательно меняется; до успешной смены обычная работа с системой запрещена. При обновлении уже установленный пользовательский пароль не должен сбрасываться.

Не откладывайте смену bootstrap-пароля.

Первоначальные учётные данные предназначены только для первого входа.

Известное ограничение

В Stable 0.61.0 не используйте split routing

Режим split routing в 0.61.0 имеет известное несоответствие fail-closed правилам.

До публикации корректирующего Stable-патча не включайте и не используйте split routing. Это ограничение не является разрешением обходить kill switch, parental DENY или другие политики безопасности. Конкретное VPN/network execution в bounded Stable-профиле также не заявляется как квалифицированная production-capability.

После входа

Выберите удобный уровень управления

«Уютный»Домой, Семья, Мой дом. Минимум настроек и готовые безопасные сценарии для телефона.
ПолныйТехнические сведения и доступные административные функции без отдельного обходного пути безопасности.

Оба интерфейса управляют одной системой. «Уютный» не создаёт отдельную конфигурацию и не обходит общие правила authorization, проверки результата и recovery.

Обновление

Используйте только квалифицированный путь из UPGRADE.md

Перед обновлением сделайте backup, скачайте официальный Stable-релиз, проверьте SHA256SUMS и следуйте UPGRADE.md именно этого релиза. Не обходите release-identity, parity, health или rollback проверки вручную.

1. Backupдо изменения установленной системы
2. Stable releaseтолько официальный канал
3. SHA-256проверка до распаковки
4. Health и rollbackпроверка до удаления предыдущей версии
Важно

Функции зависят от версии, профиля и модулей

Главная страница описывает функциональный контур Home Center. Фактическая доступность определяется установленной версией Core, release profile, модулями и квалифицированными capabilities/providers. Неподтверждённые HA, provider execution и commercial capabilities не следует считать доступными только по описанию направления развития продукта.
