Установка

Установите Home Center и начните с простого интерфейса.

Пользовательская установка выполняется из официального stable-канала. Текущий stable-пакет — Home Center 0.15.0 для Linux amd64.

Перед началом

Что понадобится

64-битный Linux-сервер, административный доступ и стандартные утилиты tar и sha256sum. Для важных данных заранее подготовьте резервную копию.

Home Center не должен самовольно перестраивать домашнюю сеть.

Routing, NAT, port-forwarding, firewall и внешний доступ включаются только отдельными управляемыми действиями.

Шаг 1

Скачайте пакет и SHA256SUMS

Откройте последний stable-релиз и скачайте пакет Linux amd64 вместе с файлом контрольных сумм.

Текущий stablehome-center-0.15.0-linux-amd64.tar.gzи SHA256SUMS из того же релиза
Скачать
Шаг 2

Проверьте загрузку

В каталоге со скачанными файлами выполните:

sha256sum -c SHA256SUMS --ignore-missing
Продолжайте только после результата OK.

Если проверка не прошла, скачайте пакет заново из официального stable-релиза.

Шаг 3

Распакуйте пакет

mkdir -p home-center-0.15.0
tar -xzf home-center-0.15.0-linux-amd64.tar.gz -C home-center-0.15.0
cd home-center-0.15.0
Шаг 4

Используйте инструкцию именно вашего релиза

Откройте docs/INSTALL-AND-UPDATE.md внутри пакета и выполните указанную там процедуру. Это защищает от расхождения между сайтом и фактическим установщиком конкретной версии.

less docs/INSTALL-AND-UPDATE.md
Первый запуск

Сразу защитите административную учётную запись

После чистой установки Home Center использует bootstrap-учётную запись admin. В релизах, где включена политика первого входа, первоначальный пароль admin предназначен только для первичной авторизации и должен быть немедленно заменён. При обновлении уже установленный пользовательский пароль не должен сбрасываться.

Не откладывайте смену bootstrap-пароля.

Обычная работа с системой должна выполняться только после установки собственного пароля администратора.

После входа

Выберите удобный уровень управления

«Уютный»Домой, Семья, Мой дом. Минимум настроек и готовые безопасные сценарии для телефона.
ПолныйУзлы, сеть, storage, сервисы, политики, monitoring, сертификаты, lifecycle и диагностика.

Оба интерфейса управляют одной системой. «Уютный» не создаёт отдельную конфигурацию и не обходит общие правила безопасности.

Обновление

Обновляйте по той же проверяемой схеме

Скачайте новый stable-релиз, проверьте SHA256SUMS и следуйте docs/INSTALL-AND-UPDATE.md из нового пакета.
