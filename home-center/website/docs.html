Home Center за четыре понятных шага

Используйте только официальный стабильный канал. Для текущей версии 0.15.0 опубликован пакет Linux amd64 и файл SHA256SUMS для проверки загрузки.

Перед началом

Что понадобится

64-битный Linux-сервер, доступ администратора и стандартные утилиты tar и sha256sum. Перед установкой Home Center убедитесь, что у вас есть резервная копия важных данных.

Home Center не должен самовольно менять домашнюю сеть.

Маршрутизация, NAT, DNS, DHCP, firewall и внешний доступ включаются отдельно, только после явного выбора владельца.

Шаг 1

Скачайте два файла

Откройте страницу последнего стабильного релиза и скачайте пакет для Linux amd64 вместе с файлом SHA256SUMS.

Текущая версия home-center-0.15.0-linux-amd64.tar.gz и SHA256SUMS из того же релиза
Скачать
Шаг 2

Проверьте загрузку

В каталоге со скачанными файлами выполните:

sha256sum -c SHA256SUMS --ignore-missing
Продолжайте только после результата OK.

Если проверка не прошла, не распаковывайте и не запускайте пакет — скачайте файлы заново из того же релиза.

Шаг 3

Распакуйте пакет

mkdir -p home-center-0.15.0
tar -xzf home-center-0.15.0-linux-amd64.tar.gz -C home-center-0.15.0
cd home-center-0.15.0

После распаковки не запускайте случайные файлы. Сначала откройте инструкцию, которая входит именно в этот релиз.

Шаг 4

Следуйте инструкции внутри релиза

Откройте docs/INSTALL-AND-UPDATE.md и используйте указанную там команду установки. Так сайт не расходится с реальным установщиком конкретной версии.

less docs/INSTALL-AND-UPDATE.md
После установки

Проверьте состояние Home Center по инструкции релиза и только затем переходите к настройке внешнего доступа, сертификатов и домашних модулей.

Обновление

Обновление — по той же схеме

Скачайте новую стабильную версию, проверьте SHA256SUMS и выполните процедуру обновления из docs/INSTALL-AND-UPDATE.md нового релиза.

4. Проверка запускадо удаления предыдущей версии
