Как установить Home Center дома

Устанавливайте Home Center только из публичного стабильного канала. Архив, контрольная сумма, установщик и документация должны относиться к одному и тому же релизу.

Перед установкой

Сначала проверьте публичный stable-канал

Текущая версия продукта — 0.14.0. При этом публичный репозиторий стабильных пакетов сейчас не содержит опубликованного установочного релиза. Поэтому мы не предлагаем команду, которая скачивает архив из закрытого, устаревшего или неподтверждённого источника.

Если страница стабильных релизов пуста — остановитесь на этом шаге.

Не используйте архив из другого репозитория и не смешивайте установщик одной версии с архивом другой. На этой странице появится обычный путь установки сразу после появления проверенного пакета в публичном stable-канале.

Открыть stable-канал
Требования

Что понадобится

Для линии 0.14.0 нужен Linux-сервер с Python 3.12+, OpenSSL, systemd, tar и sha256sum. Сборка предназначена для 64-битной архитектуры amd64.

Установщик не должен неожиданно перенастраивать домашнюю сеть.

Настройка маршрутизатора, NAT, DNS, DHCP, firewall, VPN и других сетевых функций выполняется отдельно и только после явного выбора владельца.

Шаг 1

Скачайте архив и его SHA-256

Когда stable-релиз появится, на одной странице релиза должны находиться как минимум архив Home Center и соответствующий файл .sha256. Скачивайте их парой из одного релиза.

Ожидаемый формат для 0.14.0home-center-0.14.0-linux-amd64.tar.gz+ home-center-0.14.0-linux-amd64.tar.gz.sha256
Stable releases
Шаг 2

Проверьте архив до распаковки

Перейдите в каталог с двумя скачанными файлами и проверьте контрольную сумму. Для 0.14.0 команда будет выглядеть так:

sha256sum -c home-center-0.14.0-linux-amd64.tar.gz.sha256

Продолжайте только если получено OK. Если имя архива в опубликованном stable-релизе отличается, используйте точное имя с его страницы и из соответствующего файла .sha256.

Шаг 3

Используйте установщик из того же stable-релиза

После проверки распакуйте архив в отдельный каталог и сначала прочитайте входящую в него инструкцию. Production-команда установки должна браться из docs/INSTALL-AND-UPDATE.md этого же релиза.

mkdir -p home-center-0.14.0

tar -xzf home-center-0.14.0-linux-amd64.tar.gz \
  -C home-center-0.14.0

cd home-center-0.14.0

less docs/INSTALL-AND-UPDATE.md
Почему команда установки не продублирована здесь прямо сейчас?

Публичный stable-пакет ещё не опубликован. Сайт не должен предлагать непроверенный entrypoint или параметры, которых нет в доступном пользователю пакете. После публикации инструкция на сайте будет синхронизирована с установщиком из этого релиза.

Шаг 4

Запустите и проверьте Home Center

После выполнения установщика проверьте состояние сервиса по инструкции конкретного релиза. Для systemd-установки основной контроль выглядит так:

systemctl status home-center.service
systemctl status home-center-backup.timer

Не публикуйте административный интерфейс в интернет до настройки доверенного TLS, правил доступа и выбранного способа удалённого подключения.

Обновление

Новая версия — снова как отдельный проверенный релиз

Для обновления скачайте новый архив и его .sha256 из публичного stable-канала, снова проверьте SHA-256 и используйте updater, входящий именно в эту версию. Не заменяйте файлы вручную поверх работающего каталога.

Восстановление

Откат программы и восстановление данных — разные операции

Если новый релиз не проходит readiness-проверку, используйте rollback-процедуру из его docs/INSTALL-AND-UPDATE.md. Перед обновлением держите независимую резервную копию важных данных и конфигурации.

Не удаляйте предыдущий рабочий релиз до проверки нового.

Это позволяет вернуть программу без восстановления пользовательских данных из резервной копии.
