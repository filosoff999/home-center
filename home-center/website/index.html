Пример интерфейса
01Поставьте на домашний сервер

Подойдёт отдельный Linux-сервер, мини-ПК или компьютер, который вы используете для домашних сервисов.

02Добавляйте только нужное

По мере развития можно будет подключать виртуальные машины, домашние приложения и умные устройства.

03Данные остаются под вашим контролем

Основное управление работает внутри вашей домашней сети. Доступ из интернета включается отдельно.

Для дома

Что можно делать с Home Center

Главная цель — не заставлять вас разбираться в десятках отдельных панелей. Home Center собирает самое важное в одном месте.

01
Уже сейчас

Следить за сервером

В одной панели видно состояние серверов, версию Home Center, резервные копии, сертификаты и основные проверки.

  • видно, что работает;
  • проблемы заметны быстрее;
  • не нужно помнить адрес каждой панели.
02
0.15–0.16

Управлять Proxmox и виртуальными машинами

Home Center будет видеть процессор, память, диски и сеть, а затем покажет Proxmox, виртуальные машины и контейнеры в общей панели.

  • видеть свободные ресурсы;
  • понимать, где запущена каждая машина;
  • управлять ими из одного места.
03
В разработке

Устанавливать домашние сервисы

Планируется единый каталог для файлового хранилища, медиасервисов, игровых серверов и других домашних приложений.

  • выбрать нужный сервис;
  • заранее проверить, подходит ли сервер;
  • обновлять и обслуживать проще.
04
0.17

Подключить умный дом

Устройства, комнаты и сценарии автоматизации будут собраны в одном месте. Планируется поддержка ZigBee, MQTT и Яндекс Умного дома.

  • видеть устройства по комнатам;
  • создавать общие сценарии;
  • управлять с телефона.
05
0.18

Дать доступ семье

Можно будет разделить права: например, один человек управляет сервером, а другой только пользуется домашними сервисами.

  • отдельный администратор;
  • разные права для пользователей;
  • без лишнего доступа к настройкам.
06
0.18

Подключаться из поездки

Планируется защищённый удалённый доступ. Он не будет включаться сам — владелец дома решает, нужен ли доступ извне.

  • включается вручную;
  • защищён сертификатами и правами;
  • настройки можно восстановить из копии.

Установка

Скачайте, проверьте и установите

Home Center Free 0.14.0 распространяется как архив для Linux amd64. Рядом публикуется контрольная сумма, чтобы проверить файл перед установкой. Home Center сам не меняет настройки вашего роутера или домашней сети.

Пошаговая инструкцияСкачать последнюю версию
home-center
# 1. Проверить скачанный архив
bash deploy/scripts/home-center-release.sh verify \
  --artifact home-center-free-0.14.0-linux-amd64.tar.gz \
  --checksum home-center-free-0.14.0-linux-amd64.tar.gz.sha256

# 2. После установки запустить Home Center
sudo systemctl enable --now \
  home-center.service home-center-backup.timer
