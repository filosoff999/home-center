# Home Center 0.10.0 Core API Compatibility

## Boundary

The 0.10.0 Core API is an internal planning contract. No HTTP route is
admitted by this document. The existing public `/api/v1` surface remains
unchanged.

## Envelope compatibility

| Contract | Schema identity | Compatibility rule |
|---|---|---|
| Core command | `home-center.core-command.v1` | Closed; all fields required; `mode=plan` only |
| Core result | `home-center.core-result.v1` | Closed; additive states or fields require a new schema version |
| API error | `home-center.error.v1` | Closed; bounded public code/message only |

Unknown fields, modules, actions, execution modes, and payload shapes are
rejected. A new required field, removal, type change, semantic broadening, or
new execution authority requires a new schema identity. A new plan-only action
may be added under a new action and payload schema identity without changing
existing action semantics.

## Admitted action inputs

| Module/action | Input schema | Output schema |
|---|---|---|
| `node-manager / node.drain.plan.v1` | `home-center.node-drain-plan-input.v1` | `home-center.node-lifecycle-plan.v1` |
| `upgrade-engine / upgrade.release.plan.v1` | `home-center.upgrade-release-plan-input.v1` | `home-center.upgrade-plan.v1` |
| `configuration-engine / configuration.change.plan.v1` | `home-center.configuration-change-plan-input.v1` | `home-center.configuration-plan.v1` |
| `service-manager / service.start.plan.v1` | `home-center.service-start-plan-input.v1` | `home-center.service-plan.v1` |
| `policy-engine / policy.authorize.plan.v1` | `home-center.policy-authorize-plan-input.v1` | `home-center.policy-decision.v1` |

Each input and output is closed with `additionalProperties: false`. Runtime
dispatch matches the exact module/action pair and rejects all other actions.

## Version and release compatibility

- source, package, Web, and artifact identity: exact `0.10.0`;
- immediate published predecessor: exact `0.9.2`, source revision
  `689d90995a4f365e2f19640486b136b525f29c6d`, artifact SHA-256
  `90d5cb0b657abfdd13f077b4a2347c5066fbaddcd4f4bfa6b25944e73a8abe87`;
- 0.9.x remains an independent maintenance line;
- public `/api/v1` contracts from 0.9.x are not replaced or weakened;
- no Core planner output authorizes execution or production deployment.

## Future HTTP integration gate

Any later HTTP adapter must:

1. authenticate through the existing session boundary;
2. bind actor and correlation identity server-side;
3. validate the generic envelope and exact action payload;
4. apply the exact default-deny policy;
5. return only a closed result/error contract;
6. remain plan-only until a separate privileged execution design and release
   acceptance are approved.
