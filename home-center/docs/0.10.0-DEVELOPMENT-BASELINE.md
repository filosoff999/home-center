# Home Center 0.10.0 Development Baseline

## Status

Development track initialized.

Branch:

`release/0.10.0`

## Rules

- 0.9.x remains an independent release line.
- Production dc01/dc02 are not upgraded to 0.10.0 before full release acceptance.
- Independent infrastructure and security updates remain separate from Home Center release tracks.
- No production deployment authority is created by development builds.

## Build Qualification

Required gates:

- deterministic build;
- Python 3.12/3.14 validation;
- contracts;
- tests;
- E2E;
- security checks;
- reproducible artifact build;
- SHA-256 verification.

## Release Flow

```text
Development
    |
    v
CI Gates
    |
    v
Artifact Validation
    |
    v
Beta Qualification
    |
    v
Release Acceptance
    |
    v
Production Rollout
```

## Production Rollout Policy

When approved:

```text
dc02
 -> canary/soak
 -> dc01
 -> cluster acceptance
```

Automatic update and automatic failover remain disabled unless separately accepted.
