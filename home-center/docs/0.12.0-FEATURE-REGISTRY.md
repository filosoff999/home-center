# Home Center 0.12.0 Feature Registry

Status: **ACTIVE DEVELOPMENT**

## HC-125 — Local administrator password management

### Increment 1 — node-local password change

- Web administration form and authenticated API;
- local-admin session gate plus current-password verification;
- shared provisioning/rotation complexity policy;
- node-local fresh salt and scrypt verifier;
- bounded non-persisted helper secret protocol;
- fixed `/etc/home-center/secrets/local-admin.json` target;
- atomic commit, rollback and interrupted-transaction recovery;
- runtime credential reload after helper success;
- secret-free audit metadata and response contracts;
- unit, API, UI-surface and security-negative tests.

### Increment 2 — protected local-console recovery/reset

- packaged root-only recovery entry point with no password arguments or environment input;
- physical Linux virtual-console gate (`/dev/tty1` through `/dev/tty63`) on stdin, stdout and stderr;
- one-time operator confirmation phrase before hidden password prompts;
- the same password policy and fresh-salt scrypt credential generator as normal rotation;
- atomic reset through the existing lock/next/rollback transaction;
- success evidence committed before rollback cleanup, with automatic credential rollback if evidence cannot commit;
- bounded root-only append log with strict schema and a verified SHA-256 chain;
- runtime verifier reload on every local login, so offline recovery does not require a service restart;
- negative coverage for non-root, SSH PTY, mixed TTY, confirmation, policy, tamper and rollback paths.

### Increment 3 — two-node credential transaction

- leader-only coordination through the existing authenticated administration API;
- closed peer mTLS command and result contracts with exact cluster, peer, transaction and intent identity;
- standby prepare and policy validation before any credential mutation;
- standby-first commit followed by three bounded authentication canaries and soak intervals;
- leader commit only after standby acceptance;
- fresh, independently generated salt and verifier on each node without byte copying;
- durable, secret-free phase ledger plus HMAC audit evidence;
- idempotent replay, concurrent/conflicting transaction rejection and process-restart recovery latch;
- reverse compensating rollback when the failure is determinate;
- explicit `recovery_required` result for ambiguous commit or rollback outcomes;
- two-node success, rollback, ambiguity, replay, peer API and packaging tests.
