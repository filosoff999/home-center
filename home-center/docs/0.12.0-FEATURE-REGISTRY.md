# Home Center 0.12.0 Feature Registry

Status: **ACTIVE DEVELOPMENT**

## HC-125 — Local administrator password management

### Increment 1 — node-local password change

- Web administration form and authenticated API;
- local-admin session gate plus current-password verification;
- shared provisioning/rotation complexity policy;
- node-local fresh salt and scrypt verifier;
- bounded non-persisted helper secret protocol;
- fixed `/etc/home-center/secrets/local-admin.json` target;
- atomic commit, rollback and interrupted-transaction recovery;
- runtime credential reload after helper success;
- secret-free audit metadata and response contracts;
- unit, API, UI-surface and security-negative tests.

### Deferred increments

- protected local-console recovery/reset;
- two-node prepare/commit/rollback transaction;
- independent per-node verifier/salt acceptance;
- complete 0.12 release and deployment gates.

Deferred capabilities are not implied by the node-local slice and remain unavailable until separately reviewed and merged.

Tracking: GitHub issue `#86`.
