# Home Center 0.11.0 Feature Registry

Status: **ACTIVE DEVELOPMENT**

## HC-124 — Market Module Supply Chain Foundation

### Increment 1 — admitted now

- `ModuleManifest v2` canonical JSON contract;
- bounded duplicate-key-rejecting JSON loader;
- fail-closed semantic validator;
- exact module ID and semantic version;
- Home Center compatibility interval;
- dependency/conflict consistency;
- capability and resource-scoped permission declarations;
- bounded action metadata without executable command/path fields;
- network, storage and health declarations;
- backup/restore coverage rules;
- reversible install/upgrade metadata;
- remove semantics that preserve data;
- exact artifact digest, byte size and signed-provenance identity;
- positive and security-negative tests.

### Deferred increments

- immutable content-addressed package staging;
- signature and provenance cryptographic verification;
- dependency/capability/topology planner;
- permissions review UI;
- install/update/rollback/disable/remove state machine;
- module runtime identity and isolation;
- reference stateful module acceptance.

Deferred items require separate reviewed vertical slices. The manifest contract alone cannot execute or install anything.

## Cross-release rules

- `release/0.10.0` continues independently;
- stable `main` is not moved by this development start;
- 0.10.0 changes enter 0.11.0 only through explicit compatibility review;
- 0.11.0 changes are not backported automatically;
- no production deployment before the complete 0.11.0 release gates pass.
